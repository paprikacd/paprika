# Gamma controls in Paprika Insights

These source adaptations come from the local Gamma component explorer at `/Users/benebsworth/projects/gamma`, discovered through its verified MCP endpoint and the `explore-gamma` skill. The checked source inventory, commit, hashes, reference provenance and retrieval command are recorded in [`docs/design/insights/gamma-source-catalogue.json`](../../../../../docs/design/insights/gamma-source-catalogue.json).

- `src/components/SearchCombobox.tsx`: keyboard navigation, active descendant, remote loading/error states, selection retention, and native popover positioning.
- `src/components/GammaTabs.tsx`: roving tab focus, linked tab/panel semantics and arrow navigation.
- `src/components/GammaSwitch.tsx`: native checkbox with switch semantics and animated track.
- `src/components/GammaButton.tsx`: visual variants, busy state, disabled behavior and button motion.
- `src/components/ActionMenu.tsx`: menu-button semantics, enabled-item navigation, selected and danger states, focus return.
- `src/components/DisclosureStack.tsx`: native expanded/controls/labelled-region semantics and the rotating plus affordance for import comparisons. The current source and component brief were retrieved through Gamma MCP. `GammaDisclosure` adapts one disclosure per comparison card and mounts large diff bodies only while open; it keeps the indicator motion and reduced-motion handling without animating a large document's height. Nexvyn/UI is the upstream catalogue's behavior reference, not imported source or a licensing grant.
- `src/components/SideSheet.tsx`: native modal lifecycle and deliberate focus return adapted in `confirmation.tsx`. Paprika uses a compact alert dialog with Cancel initially focused; it does not copy the sheet layout or add a morph effect. The current source and brief were retrieved through Gamma MCP during the widget review.
- `src/components/FloatingField.tsx` and `SearchField.tsx`: native input semantics and focus/invalid/disabled token treatment. The `GammaInput`/`GammaTextarea` adapters preserve existing visible form labels and native events rather than importing the floating-label/password-reveal wrapper.
- `src/components/library.css` and `src/design-systems/gamma.ts`: 9px controls, 12px panels, 130/200ms motion and focus treatment.

`GammaSelect` is explicitly a select-only adapter of Gamma's maintained SearchCombobox and ActionMenu behavior. Gamma has no separately catalogued maintained native select component. It uses listbox semantics for values; actions use `GammaActionMenu` and menu semantics. The select preserves the committed value on dismissal, supports Home/End, arrows, typeahead, disabled choices and optional search. Search filters the full supplied collection while rendering at most 100 matches; ordinary selects expose every option. The selected value submits via a hidden native field when `name` is provided. Options can supply a decorative `icon`, non-interactive `details`, and a concise `accessibleLabel`; supporting details remain available through `aria-describedby`. Search includes descriptions and supplied keywords. Rich saved-query menus use this contract for artwork, tags and metadata.

Paprika adaptations: controlled tab/switch APIs; collision-free React IDs and Home/End tab keys; portals with inherited token copies; collision detection against the visual viewport, flipping and scroll/resize tracking; CSS modules and locally scoped paper, paprika and sage tokens. Portals use the body normally and the nearest open native dialog when inside a modal, so menus remain in the interactive top layer. They replace the upstream native popover so every browser surface follows one positioning path. Escape returns focus, Tab continues from the trigger, and outside interaction dismisses. No Gamma app runtime, font download or global stylesheet is imported. Reduced-motion preferences disable decorative transitions. The query builder permits custom metric/label entries through an explicit combobox option. Explore stages generated expressions until applied and runs queries explicitly; the widget editor opts into live valid-expression previews while retaining dashboard Save as its persistence boundary.

Add `gammaTheme.scope` from `gamma-theme.module.css` to the Insights root. The theme preserves Gamma's semantic token names, interaction behavior and easing, with Paprika's palette and existing font. Paprika's compact workspace direction uses 5px controls, 6px panels, flat buttons and fields, and elevation only for overlays. Individual adapters preserve caller layout classes; their component rules own visual states. `GammaButton` retains primary/secondary/quiet and size/loading props, adds `ghost` as a quiet alias and a semantic `danger` variant, defaults to secondary priority and `type="button"`. Mark a visually icon-only action with `iconOnly` and an accessible name; CSS `svg:only-child` cannot distinguish icons from icons followed by text nodes. Phone and coarse-pointer targets are at least 44px. `GammaInput`/`GammaTextarea` forward native refs/events/validation; hidden and file inputs pass through unstyled. They do not add a second label or form. Code fields can set `--gamma-field-min-height`, `--gamma-field-font`, and `--gamma-field-font-size` without fighting shared input specificity. Selected normal-size text uses Paprika's darker `--gamma-accent-text` on the soft accent surface; the primary background retains `--gamma-accent`.

Validation covers portaled rendering, viewport collision, focus retention/return, disabled options, typeahead, keyboard navigation, large-list search, outside dismissal, controlled values/native form submission, forwarded refs and busy actions. Run `npx vitest run src/features/insights/gamma` from `ui`; the live browser suite verifies the integrated dashboard controls at desktop and phone sizes.

The guided query serializer follows the [Prometheus selector and string literal rules](https://prometheus.io/docs/prometheus/latest/querying/basics/) and [aggregation syntax](https://prometheus.io/docs/prometheus/latest/querying/operators/). It validates identifier/operator structure and JSON-quotes label values (compatible with PromQL double-quoted string escaping). It intentionally generates a documented subset instead of parsing and rewriting arbitrary PromQL. Full expressions and UTF-8 metric names remain available in the raw editor.

For freeform graph-label bindings, SearchCombobox's `onQueryInput` reports direct text edits only. `onQueryChange` also reports search resets on focus/selection and must not be used to update a persisted binding. Widget settings tabs wrap within their container so every tab stays visible at narrow inspector widths. Saved-query selects retain compact tag context in both open options and the closed selected trigger.

Insights appearance uses `data-insights-theme="light"` or `"dark"` on the scoped root. `useInsightsTheme` resolves the browser's Light / Dark / System preference, stored separately from dashboard documents; System follows live OS changes. Dashboard surfaces, variable filters and chart defaults use the same neutral white/charcoal palette with a paprika accent. Default series use `--gamma-chart-1` through `--gamma-chart-8`, with stronger dark-mode strokes. Explicit custom widget background, text and series colors remain author-controlled. `inheritGammaTheme` copies the originating scope's tokens and color scheme into menus and observation/chart tooltip portals, observing root theme changes while they remain open. Other product routes keep their existing appearance.
