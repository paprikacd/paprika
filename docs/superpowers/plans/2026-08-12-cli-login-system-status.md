# Paprika CLI Login and System Status Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a secure browser-based `paprika login`, an authorized `paprika status`, and Secret-backed OIDC deployment configuration, then merge and validate the feature on omega VKE.

**Architecture:** The CLI uses Paprika's existing OIDC authorization-code endpoints with an exact loopback redirect, in-memory PKCE/state, and a bounded one-shot callback listener. A new read-only status RPC loads one immutable fleet snapshot, authorizes its project candidates, and aggregates only visible applications. Helm and deployment workflows move the OIDC client secret out of process arguments and into a referenced Kubernetes Secret.

**Tech Stack:** Go 1.26, Cobra, `net/http`, Connect RPC, Protocol Buffers/Buf, controller-runtime, Helm, GitHub Actions, Kubernetes/VKE.

**Required skills during execution:** @superpowers:test-driven-development, @security-best-practices, @superpowers:verification-before-completion, @superpowers:requesting-code-review, @superpowers:finishing-a-development-branch.

- [ ] **Step 4: Add the bounded OIDC configuration**

Implement these exact field additions and contracts in `oidc_auth.go`:

```go
const (
    CLIRedirectURL       = "http://127.0.0.1:17632/callback"
    maxTokenResponseSize = 1 << 20
    oidcHTTPTimeout      = 15 * time.Second
)

type OIDCConfig struct {
    IssuerURL     string
    ClientID      string
    ClientSecret  string
    RedirectURL   string
    Scopes        []string
    GroupsClaim   string
    EmailClaim    string
    NameClaim     string
    HTTPClient    *http.Client
}

func (o *OIDCAuthenticator) validateRedirectURL(raw string) error {
    if raw == o.oauth2Config.RedirectURL || raw == CLIRedirectURL {
        return nil
    }
    return errors.New("redirect URI is not allowed")
}
```

Default a nil client to `&http.Client{Timeout: oidcHTTPTimeout}`. Store it on the authenticator and never use `http.DefaultClient` for provider exchange. Pass the same client to OIDC discovery and JWKS retrieval by calling `oidc.NewProvider` with a context containing `oauth2.HTTPClient`, so every provider-controlled HTTP call is bounded.

- [ ] **Step 5: Validate redirects at both HTTP boundaries**

- [ ] **Step 6: Bound and redact provider responses**

```go
return nil, fmt.Errorf("token endpoint returned HTTP %d", resp.StatusCode)
```

Do not include provider bodies, codes, verifier values, or secrets in errors.
