## Authority

The unchecked acceptance criteria in each feature specification are copied from its primary issue body. Related issue links indicate dependencies or adjacent work; they do not broaden a first slice. JSON fixtures preserve exact synthetic values and action constraints. Generated raster geometry does not override those values.

The F01U–F29U studies use the retained common prompt and feature prompts in generation-prompts.json. The 44 reviewed exploratory PNGs are also archived at full resolution. All assets are copied without changing their depicted content. The asset manifest records dimensions, hashes and review status for the final files.

## Review boundary

Fixture arithmetic, state transitions, identities, available actions, readable controls and explicit missingness are the visual review targets. A concept's appearance does not establish browser accessibility, runtime responsiveness, source freshness, production authorization, controller behavior or deployment success. Those checks belong to implementation.
