# Creative exploration archive

This archive retains all 44 reviewed exploratory PNG studies at their original resolution. They record the visual exploration that preceded the 29 canonical Working System artboards. The feature specification and exact fixture remain the behavioral reference; the canonical artboard supplies the shared visual direction.
