## Prompt

Use case: stylized-concept. Asset type: art direction concept board for the Paprika open-source Kubernetes delivery landing page; inspiration, not a factual product screenshot.

A polished wide editorial board with three distinct isometric software delivery diagrams, designed as one coherent visual system. Make the diagrams recognizable as software deployment rather than generic industrial machines.

Pale paper #f2f2f3, generous negative space, precise technical grid and quiet studio shadows. Navy #1d2d3d and steel blue #5980a6 with restrained amber for approval and red for failure. Crisp square surfaces and fine construction lines.

Panel 1: Git commit card and Application specification feed an optional branching Pipeline of container Job cards. Rendered YAML manifest sheets connect to a Release record and a Kubernetes target platform with Deployment and small Pod blocks. A fine return observation line suggests health and sync evidence.

Panel 2: three genuinely separate deployment target islands labeled DEV, STG, PROD. Above them, a thin management-plane rail holds separate Application records and verification Job cards. Dotted test probes point back to upstream target islands. A production approval hold is shown as a small amber status card. No conveyor belt and no moving image packages between clusters; matching tiny SHA reference tags imply one pinned Git revision selected independently.

Panel 3: paired desired manifest sheet and live Kubernetes resource card, with a visible replicas field difference and two versus three Pod blocks. Make comparison and health separate visual concepts.

Style: refined isometric architectural diagram, tactile matte technical UI objects, restrained 3D depth, readable software symbols, contemporary developer tool identity. Condensed engineering display type with monospaced technical labels.

Exact large text: DEPLOY, PROMOTE, INSPECT. Small environment labels: DEV, STG, PROD. Other tiny labels may be abstract lines.

Avoid factory presses, elevators, engines, pipes, gauges, gears, people, testimonials, customer logos, invented adoption claims and vendor integration logos. Distinct compositions, consistent camera and materials. Wide landscape composition.
