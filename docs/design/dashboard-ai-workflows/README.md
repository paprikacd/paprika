# Dashboard AI and workflow design studies

Sixteen numbered design studies connect Paprika Insights improvements with future AI operations and agentic workflows. The images are synthetic concept references, not screenshots of implemented features or measured production telemetry.

The maintained specifications and review notes are in the [Paprika knowledge base](https://chatgpt.com/space/page_6ae45780924881918c18270064f72c2c). This repository copy makes the same images available to GitHub issue readers. The [manifest](manifest.json) records image identities, source pages and byte digests.

## Reading the studies

Studies 01–04 preserve the exploration history. The reviewed dashboard direction is 05–08, with 05 and 06 forming a controlled Light/Dark pair. All chart coordinates and calculations must be derived from native fixtures; image geometry is illustrative.

The service fixture separates selected 10:18 values (p95 284 ms, 1,240 req/s, 5xx 0.42%) from latest 10:30 values (p95 197 ms, 1,200 req/s, 5xx 0.18%). The expected minute samples total 31; 10:22, 10:23 and 10:24 are missing, leaving 28 observed. Metric coverage and partial trace-query coverage have separate meanings.

Studies 09–16 explore proposed product capabilities. Evidence, hypotheses, scenarios, plans and execution receipts have distinct statuses. Workflow Draft v8 and Action Draft v3 are authoring states; the pictured run remains pinned to Workflow v7 and Action v2. A checked procedure or a successful configuration action does not by itself establish incident recovery.

The main console's existing design contract and independently themed Insights surfaces retain their scopes. Dark workflow concepts are an exploration alongside [Paprika Working System v1](https://chatgpt.com/space/page_83d1294312088191bf8b0b831d680eb2), not a wholesale shell replacement.

## Acceptance and provenance

Use the specifications' fixtures, acceptance criteria and issue links when implementing. Validate analytical truth, task hierarchy, interaction continuity, accessibility, persistence and measured performance independently. Exact values update immediately; animation presents state without changing or delaying it. Spatial graphs need an equivalent ordered view and keyboard/non-drag operation.

The existing source-capability review is pinned to [`17a651ab8edf20337ac5319af93ae7fb2c389b47`](https://github.com/paprikacd/paprika/tree/17a651ab8edf20337ac5319af93ae7fb2c389b47). This publication adds documentation and images only. It does not install an orchestration runtime, change a CRD, run an operational action or establish deployed capability.

Generated reference images are preserved byte-for-byte from the authorized source pages. Studies 09 and 11 are the reviewed refinements; the earlier superseded versions are not included.
